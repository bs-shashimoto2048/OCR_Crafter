# 06. 評価結果の見方

モデル評価画面（[05_モデル評価.md](05_モデル評価.md)）に表示される数値を、初めて見る方向けに説明します。数式よりも「何を表しているか」を重視します。

## Accuracy（完全一致率）

```
Accuracy
  ↓
どれくらい完全に正解したか
```

OCR Crafterでは「完全一致率」として表示されます。1枚の画像に対して、OCRが読み取った文字列が正解ラベルと**1文字も違わずぴったり一致したか**を、全画像に対する割合で表します。

- 100%に近いほど良い
- 「99%正解に近いけど1文字だけ間違えた」場合も「不一致（0点）」として扱われる、やや厳しい指標です

## CER（文字誤り率）

```
CER
  ↓
文字単位でどれくらい間違えたか
```

CER（Character Error Rate）は、正解文字列とOCR結果を1文字ずつ比較し、「置き換え・抜け・余分な挿入」がどれくらいあったかを全体の文字数に対する割合で表した指標です。

- **低いほど良い**（0%＝完全に一致、100%＝すべて間違い）
- Accuracy（完全一致率）と違い、「10文字中1文字だけ間違えた」場合はほぼ正解に近い低い値になります。1文字単位で細かく精度を見たい場合に向いています
- OCR Crafterでは**この指標が主指標**です。全画像の編集距離（間違いの数）の合計 ÷ 全画像の正解文字数の合計、という計算方法（マイクロ平均）を採用しています

補助的に「文字正解率」（＝1−CER）も表示され、こちらは「高いほど良い」向きで直感的に読めるようにしたものです。

## WER（単語誤り率）

```
WER
  ↓
単語単位でどれくらい間違えたか
```

**現時点では未対応**です。OCR Crafterは1文字ずつの認識・評価（CER中心）を前提としており、単語単位の誤り率は計算されません。

## Precision（適合率）

**現時点では未対応**です。

## Recall（再現率）

**現時点では未対応**です。

## F1（F1スコア）

**現時点では未対応**です。Precision・Recallを組み合わせた指標ですが、いずれも実装されていないため算出されません。

## まとめ表

| 指標 | 状態 | 一言でいうと |
|---|---|---|
| Accuracy（完全一致率） | 実装済み | 1文字も違わず正解した画像の割合 |
| CER（文字誤り率） | 実装済み（主指標） | 文字単位でどれくらい間違えたか（低いほど良い） |
| 文字正解率（1−CER） | 実装済み | CERを「高いほど良い」向きに直した参考値 |
| WER（単語誤り率） | 現時点では未対応 | 単語単位でどれくらい間違えたか |
| Precision（適合率） | 現時点では未対応 | - |
| Recall（再現率） | 現時点では未対応 | - |
| F1スコア | 現時点では未対応 | - |

## その他の補助情報

- **混同TOP**: どの文字がどの文字に間違えられやすいか（置換・脱落・挿入）を上位から表示します
- **改善・同等・悪化件数**: 学習前モデルと学習後モデルを比較したとき、画像単位でどれだけ良くなった/変わらない/悪くなったかを集計したものです
- **Evaluation Hash**: 評価条件（データセット・前処理・エンジン・Whitelist等）が同じかどうかを判定するための値です。**Evaluation Hashが異なるモデル同士のCERは、条件が違うため単純比較できません**（画面に警告が表示されます）
