# 08. FAQ

コードから確認できる内容のみを記載しています。

## Datasetが作れない

- **前処理未実行の警告が出る**: OCRデータ作成はDataset作成時に必ず前処理を自動実行するため、警告が出ても作成自体は止まりません。ただし前処理設定画面で一度も前処理を実行・確認していない場合は意図しないパラメータで前処理される可能性があるため、警告が出たら先に前処理設定を確認することを推奨します
- **charset外の文字を含むラベルが多い**: charset外の文字を含む画像は自動的に除外（skipped）されます。除外件数が多い場合はラベルまたはcharset設定を見直してください
- **ラベル未入力の画像が残っている**: ラベル編集画面で未編集フィルタを使い、未入力の画像がないか確認してください

## 学習できない

- **同一プロジェクトで学習が二重実行される**: 同一プロジェクト・同一系統でアクティブな学習ジョブがある場合、新しい開始要求は409エラー（`JOB_CONFLICT`）で拒否されます。「運用 > ジョブ管理」で実行中のジョブを確認してください
- **Tesseract学習ツールが未導入**: 学習ツール（`lstmtraining`等）が導入されていない場合、学習は失敗します。[../11_TESSERACT_CHECKLIST.md](../11_TESSERACT_CHECKLIST.md) を参照してください
- **Backendを再起動してしまった**: 学習中にBackendを再起動すると、そのJobは「中断（再起動）」（`interrupted`）となります。ジョブ管理から再実行できます

## 評価できない

- **Tesseract本体が未導入**: Tesseractを導入し、`tesseract.tesseract_cmd`またはPATHを設定してください
- **eng.traineddataが無い**: tessdata_bestを配置し、`tessdata_dir`を指定してください
- **正解CSVが不正**: 形式（`filename,text`）とファイルパスを確認してください
- **画像未検出N件と表示される**: 正解CSVの`filename`列と、評価用画像フォルダ内のファイル名が一致しているか確認してください
- **PaddleOCRモデルの評価ができない**: OCRモデル評価は現時点ではTesseract専用です。PaddleOCRモデルの評価はこの画面では未対応です

## モデルが表示されない

- **モデル管理の一覧に出ない**: 学習が`completed`になっているか、「運用 > ジョブ管理」で確認してください。学習が失敗（`failed`）の場合はモデルは作成されません
- **PaddleOCRモデルで推論・ダウンロードができない**: PaddleOCRで推論・ダウンロードできるのはexport済みモデルのみです。学習完了時に自動でexportされますが、旧モデルは一括変換（`POST /api/ocr/models/export-migrate`）が必要な場合があります

## 推論モデルが切り替わらない

- **「推論に使用」ボタンが押せない（グレーアウトしている）**: そのボタンの対象モデルが、すでに現在の推論使用モデル自身である場合は「推論使用中」として無効になります（仕様どおりの動作です）。別のモデルのボタンであれば、有効になっているはずです
- **切替後、別画面で選んでいるモデルと違って見える**: 推論・OCR修正・バッチ推論画面のモデル選択は「試し撃ち用」の表示であり、モデル管理で「推論に使用」により保存された選択とは独立しています。これらの画面で別モデルを選んでも、保存済みの推論使用モデルは変わりません
- **保存済みモデルが一覧に見当たらないという警告が出る**: 以前保存したモデルが削除・移動された場合に表示されます。別のモデルを改めて「推論に使用」で設定してください（自動的に別モデルへ置き換わることはありません）
